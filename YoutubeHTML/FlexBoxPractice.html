Its a flexible box because it expands to accomodate as much space as it needs to. In addition, when the elements are moved, they move with their widths which is very contrary to Grids which are RIGID. Flex boxes can also be used to create Horizontal layouts while maintaining the vertical alignment. Just like Grids, to create flexboxes, an outer CONTAINER DIV element is needed to set the properties that the inner div elements will follow. For instance, it can be used when the developer wants a flexible HEADER dependent on the context, ie to show more or less elements.
